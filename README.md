# 📝 My Sticky Note App

A lightweight, minimal, and customizable **Sticky Note desktop application** built with **JavaFX**.  
Designed to give you a clean, distraction-free way to jot down notes with **custom accents, textures, and a paper-like feel**.  

---

## ✨ Features

- 📌 **Multiple Notes**  
  Create, open, and manage multiple sticky notes.

- 🎨 **Custom Accents & Backgrounds**  
  Choose from **colors** (Teal, Slate, Coral, etc.) or **paper textures** for your note background.  

- 🖌️ **Editable Titles**  
  Rename notes directly from the top bar.  

- 🗂️ **Notes List**  
  Quickly switch between saved notes.  

- 💡 **Themes & Styling**  
  - Paper-like textured background option.  
  - Accent color tiles with hover effects.  
  - Warm "off-white paper" theme for a natural note-taking vibe.  

- 🖥️ **Resizable Notes**  
  - Drag from edges/corners to resize.  
  - (Planned) Trackpad gestures (pinch/zoom) and **Ctrl + Scroll** resizing.  

- ⚡ **Lightweight Runtime**  
  Packaged with a **custom Java runtime** using `jlink` & `jpackage`.  
  No need to install Java separately!  

- 📂 **Portable**  
  Works as a standalone `.exe` installer on Windows.  

---

## 🛠️ Tech Stack

- **Language:** Java 21+  
- **UI Framework:** JavaFX 21  
- **Build Tool:** Maven  
- **Packaging:** `jlink` + `jpackage`  
- **Platform:** Windows (EXE installer), cross-platform build possible
